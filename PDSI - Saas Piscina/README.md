# PDS-TSI-2026 — Piscineiro SaaS

Repositório do projeto final da disciplina de Projeto e Desenvolvimento de Software (PDS) do curso de Tecnologia em Sistemas para Internet (TSI), 2026.

## Sobre o projeto

**Piscineiro SaaS** é uma plataforma para contratar a limpeza de piscina por assinatura mensal e acompanhar o contrato. Proprietários de piscinas têm dificuldade para contratar uma limpeza periódica confiável, com dia, horário e preço combinados; a plataforma resolve isso com contratação online e uma área do cliente.

**Escopo:** Contratação e Área do Cliente.
